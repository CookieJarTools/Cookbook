# Changelog

All notable changes to this package are written here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this package follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-10-13

### Changed

- The tool is spelled **CookBook** everywhere it shows its own name: the window and its tab, the
  breadcrumb, the home heading, every dialog, the progress bars and the warnings it writes to the
  console. The doc comments that surface in the Code Reference say it too.
- It opens from `Window > CookieJarTools > CookBook`, and the asset menu is now
  `Assets > CookBook > Add to Code Reference`.
- The Go to Page shortcut is listed under `CookBook` in the Shortcuts window. A key you had bound
  to it yourself needs binding again.
- New pictures in the readme, taken with the renamed window.

### Unchanged

- Where your pages are kept, which code is in the Code Reference, and the panel choices you have
  made. The settings file, the saved keys and the package id are all spelled as they were, so
  nothing you have written or set is lost.

## [0.1.0] - 2026-09-23

### Added

- The package, as it stands: in-editor documentation: Markdown pages in folders, with images, search, step-by-step guides, and links from code.
