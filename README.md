# Cookbook

In-editor documentation: Markdown pages in folders, with images, search, step-by-step guides, and links from code.

## Installing

Window > Package Manager > + > Install package from git URL:

```
https://github.com/CookieJarTools/Cookbook.git
```

## Using it

Open it from **Window > CookieJarTools > Cookbook**. Pages are Markdown files in a `Docs` folder at the top of your project; write them in the editor or in any text editor.
